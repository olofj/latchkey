# simulators longest first by these numbers; a test missing here is given a
# default and named in a warning. Each sharded run writes the durations it
# measured to durations.txt in its log directory, in this format, to refresh
# from.

# Tests that share one launch must land on one shard, or each shard pays the
# launch and the sign-in again — scripts/shards.py keeps each group together.
# Within a group the carrier holds that cost and the others read the same run,
# which is why they measure about 0.1 s.
#
# These figures are from an eight-way run, where test time runs about 1.39x
# its serial cost because the suite drives the real KiroCrew bundle in WebKit.
# They are the right numbers for packing an eight-way run, not an estimate of
