### 1. HIGH — Relay listener is bindable by any co-resident app; SOCKS credential exposed
`app/TSNet/SocksLogProxy.swift:174` sets `allowLocalEndpointReuse = true` on the loopback `NWListener` (OS-assigned port, so reuse buys nothing). Network.framework implements this with `SO_REUSEPORT`; on iOS every app runs as uid `mobile`, so another app can bind the same `127.0.0.1:&lt;port&gt;` and take WebKit's connections. It answers the greeting with method 0x02 and receives `tsnet:&lt;proxyCredential&gt;` plus every CONNECT target, which the relay forwards verbatim (`:36`, `:551-561`). With that credential it can use tsnet's real listener (plain Go `net.Listen`, `SO_REUSEADDR` only — `tsnet.go:457`, Go `sockopt_bsd.go:41` — so not itself hijackable) and reach the tailnet as this node.

### 2. MEDIUM — Node start failure is a crash loop
`app/TSNet/TSNetManager.swift:187-189` `fatalError`s on any throw. `TailscaleNode.init` throws when `tailscale_start` is non-zero (`TailscaleNode.swift:80-84`); `tsnet.go:968-974` fails on an undecodable `tailscaled.state`, `:863` on an unwritable state dir.
